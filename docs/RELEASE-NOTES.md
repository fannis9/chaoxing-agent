# 本地工程化更新（2026-11-19）

此更新已安装到当前 Windows 工作区，未提交或发布到远端。

## 升级注意

- 控制台接口要求配对令牌。首次启动后在侧栏连接设置中保存本机令牌。
- Page Bridge CLI 必须支持 `tabs --json`；本工作区上级仓库的 CLI 已同步修改。仅复制控制器到其他电脑时，也要更新对应 CLI。
- 需要 Node.js 22+。从旧版本升级后重新加载浏览器扩展。
- 模型支持 Responses 与 Chat Completions；需选择供应商实际支持的协议。
- 不确定或素材缺失的答案进入人工复核；不再随机猜选。保存复核结果只修改本地文件，继续队列才恢复填写与提交。
- 提交中断后先核验平台证据；无法确认时进入检查状态，不重复提交。

## 使用变化

侧栏保留编辑草稿、绑定运行标签，并提供首次配置检查、课程预览和排序、人工复核、模型能力检测、脱敏诊断及可恢复归档。单章脚本由共享源码生成。日志轮转，停止流程提供协作取消与限时强制退出。

安装、配对、后台启动及数据维护步骤见 [本地安装说明](LOCAL-SETUP.md)。Windows 后台入口 `dev/start-console.ps1` 已在本机运行验证，不注册自启动。其他系统服务模板与三系统 CI 已提供，但尚无实际 macOS/Linux 部署或远端 CI 运行证据。

## 验证范围

21 个隔离测试入口通过；后续连接遥测、PNG 校验和日志启动错误修复分别通过针对性回归。真实 Edge 侧栏连接与展示已确认；实际 DeepSeek 文本、结构化输出、图片输入三项检测通过。未使用真实课程提交作业作为验收，图片接口接受请求不代表解题准确率。

密钥、配对令牌、聊天和课程数据保留在本机且被 Git 忽略。部署时保留状态目录，迁移前停止队列并备份；不要将 `.env` 或报告目录作为公开发布内容。
