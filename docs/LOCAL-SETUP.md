# 本地安装与验证

需要 Node.js 22 或更新版本，Chrome 或 Edge，以及已授权的 Page Bridge。

1. 在本仓库运行 `npm ci`。
2. 复制 `.env.example` 为 `.env`，配置模型和 `CX_PAGE_BRIDGE`。
3. 运行 `npm run doctor`。加 `-- --bridge` 可只读检查桥接连接。
4. 运行 `npm run console`。启动只开启控制台，不自动运行课程。
5. 在浏览器扩展管理页加载本仓库 `extension` 目录。
6. 打开侧栏“连接设置”，粘贴本机 `quiz-reports/console-token` 文件内容并保存配对。

令牌不是模型密钥；不要发给他人或提交到 Git。令牌保存在浏览器本地扩展存储。
模型密钥只保留在本机环境中。升级扩展后需重新加载扩展。

可用 `CX_QUIZ_REPORT_DIR` 改变状态目录；`CHROME_PATH` 指定浏览器。
默认探测 Windows Chrome/Edge、macOS Chrome/Edge 和 Linux Chromium。
自定义控制台端口时，在侧栏“连接设置”填写相同端口。服务始终只监听回环地址。

控制器要求 Page Bridge 的 `tabs --json` 返回结构化标签数组。本工作区的 Page Bridge CLI
已补齐该能力；分发到其他电脑时需同时更新桥接 CLI，旧版本会明确报协议不兼容。

启动时绑定当前学习通标签，继续时保持原标签；切到其他页面不会转移控制对象。
“课程队列设置”可读取当前课程、选择首末任务章节、核实总任务数并调整课程顺序。
识别不出的任务总数不会猜测；保存替换配置前会写入 `.backup` 备份。
保存课程不会清除旧检查点；队列与检查点不符时会停止并要求核验。

测验阶段保存到 `phase-*.json`。若上次停在提交阶段，重启先核验对应任务是否完成，
不能确认时不会重复提交。仅切换章节或脚本继续运行不再作为成功依据。

单章脚本是生成产物，只编辑 `chaoxing-autoplay-v3.js`，然后运行
`npm run build:scripts` 更新；`node dev/build-scripts.mjs --check` 可检查是否同步。

暂停会取消在途子进程并停止页面脚本；如果无法确认页面停止，会显示需要检查。
已发生的点击无法撤销。低置信度、弃答或素材缺失进入复核，禁止随机猜选后提交。

`npm test` 使用隔离页面，不连接真实学习通账户。
Windows 不支持 POSIX mode 的相同语义，因此权限位断言只在 POSIX 系统运行；
Windows 部署需依赖用户目录 ACL。

完整实施状态见 `IMPLEMENTATION.md`。当前版本仍在实施，尚未完成全量生产验收。


## 模型与人工复核

侧栏可选择 Responses 或 Chat Completions。基础地址不含具体接口路径，模型 ID、密钥变量名与供应商配置一致。“检测模型能力”分别请求文本、结构化输出和微型图片，会产生供应商调用费用。图片检测仅证明接口接受图片，不能证明识图准确率。

先暂停队列，在“人工复核”读取报告、核对原页面并修改答案。图片或字体缺失必须在原页面核对确认；控件映射缺陷不能通过勾选绕过。保存仅写本地答案，点击“继续”才恢复填写和提交。题目内容变化使旧复核失效，仅采集时间变化不会。重新请求模型保留同份报告已确认的人工答案。

## 维护与部署

可在 `.env` 设置 `CX_AI_SKIP_UNAVAILABLE=1` 并重启控制台，启用 AI 判断坏题跳过。
仅在平台明确提示教师未创建、测验未发布或已删除、且没有题目时请求模型判断；
普通加载超时、登录或验证码不会自动跳过。导航前再次核验课程和章节。
跳过记录及模型理由写入状态目录的 `skipped-quizzes.jsonl`，状态为待补做，不标记完成。
模型拒绝、请求失败、页面变化或无法确认下一节时保持停止。设为 0 可关闭此功能。

另可设置 `CX_SKIP_QUIZ_ERRORS=1`：答题失败、答案需复核或页面填答失败时，按用户选择跳过整份测验并继续后续章节，记录为待补做，不提交不完整答案。它不会将跳过计入完成。登录/验证码、无法确认下一节等情况仍停止。当前本机已按用户要求开启此项。

该错误跳过策略也覆盖已达到等待上限的视频：30 秒找不到可播放媒体、连续 90 秒无播放进展，或播放等待结束仍未获平台完成确认。再次确认当前章节确有未完成视频、且没有登录或身份核验提示后，记录待补做并进入下一节；不修改平台完成标记。未知播放器错误仍走恢复重试。

全自动模式下，其他章节故障交给配置的 AI 模型判断，动作限定为刷新、重试、跳过；页面文字不能直接执行代码。每章最多两次刷新/重试，次数持久化在 `recovery-attempts.json`；每次动作及模型理由写入 `recovery-events.jsonl`。模型超时或返回非法动作时，采用同样受限的重试/跳过策略。导航前重新核验章节，跳过后确认章节已变化；末章沿用课程审计和切课流程。遇到登录或身份验证等待本人处理。缺少有效导航入口时不会猜测点击目标，仍需后续恢复处理。

事件日志和后台控制日志按约 5 MB 轮转，保留三份历史文件。侧栏可预览并归档超过期限且确认提交的报告，保留未完成报告和阶段检查点。归档在状态目录的 archive 下；恢复前先停队列，再将对应文件移回。脱敏诊断不含题目、答案、聊天、URL 或密钥。

`npm run service:files` 在状态目录生成 Windows 计划任务、macOS launchd 和 Linux systemd 模板，不注册或启用自启动。检查路径后自行安装。CI 定义覆盖三个系统的 Node.js 22；本机 Windows 测试通过，远端 CI 尚未执行。

Windows 也可在 PowerShell 运行 `./dev/start-console.ps1`，以隐藏窗口的后台进程启动控制台，关闭终端后仍运行；此命令不注册开机自启动。启动日志位于 `quiz-reports/service`。不要在已有控制台运行时重复启动；重复启动会因端口占用退出。模型密钥修改后需重启控制台。

## 登录后全自动

本机已启用 `CX_AUTOMATION=1`。首次发现登录后，控制台读取账户课程列表，排除明确已结束课程，并读取各门课目录；队列与检查点保存在状态目录的 `automation-queue.json`、`automation-courses.json`、`automation-schedule.json`。

调度器优先接续当前课程，断线后等待浏览器，重新登录后恢复；验证码或人脸验证等待本人完成。临时目录错误会重试，无法处理的课程列为不可用；跳过测验保持待补做。完成汇总区分已完成和已处理但仍有未完成任务。

侧栏“全自动模式”可以启用/关闭自动调度。手动暂停或停止会持久化，重启不会擅自继续；点击“继续”恢复。安装或更新侧栏后需重新加载扩展。

Windows `dev/install-autostart.ps1` 安装当前用户任务 `ChaoxingPageBridgeConsole`，在系统登录时启动，失败后一分钟重启。任务通过 `wscript.exe` 的 GUI 宿主隐藏启动 Node，不启动 PowerShell 窗口。可在任务计划程序中禁用或删除同名任务；这不删除本地课程数据。该任务不会替你输入学习通账号密码。
