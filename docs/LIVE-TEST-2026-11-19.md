# Windows / Edge 实机测试（2026-11-19）

用户请求实机测试时，调度器已经运行；页面因视频状态不明确停止，控制台仍显示运行中。

## 发现与修复

1. 主页面桥接执行异步表达式返回空对象，导致停止确认误报。改为同步发送停止指令，由 Node 轮询页面活动状态。实机暂停返回 paused。
2. 页面 incident 未停止调度器，运行状态与页面不一致。现在停止调度器并标记 needs-review；隔离集成测试验证子进程退出和状态同步。侧栏允许检查后继续。
3. 附件元数据与完成标记可能异步到达。未知状态最多等待八秒，仍无明确证据则停下，不将缺失标记视作完成。延迟完成标记的浏览器回归通过。

## 实机结果

在当前已完成任务的章节运行单章脚本，平台文档、视频完成状态均被识别；核验两个任务后进入 limit，active=false，没有点击下一节。调度器保持暂停。

本次未测试尚未完成的视频的完整播放周期，也未填写或提交真实测验。不能把已完成任务的识别测试等同于完整课程无人值守验收。

21 个测试入口通过，新增延迟标记与 incident 自动停止的针对性回归通过。侧栏源码更新后需在扩展管理页重新加载，才会显示新的“需要检查时继续”按钮逻辑。
